# P-tuning: виртуальные токены

P-tuning обучает непрерывные «виртуальные токены», которые добавляются перед входом; веса модели заморожены.
Число виртуальных токенов: 10–30 для классификации, 20–100 для генерации. Больше токенов — больше ёмкость,
но длиннее последовательность (нужно учитывать в max_seq_len).

# P-tuning: энкодер подсказок

Виртуальные токены параметризуются энкодером (MLP или LSTM). MLP с 2 слоями и скрытым размером 128–512 —
надёжный выбор по умолчанию; LSTM иногда стабильнее на малых данных, но медленнее.

# P-tuning: learning rate

Поскольку обучается только энкодер подсказок, lr для P-tuning заметно выше, чем для LoRA: 1e-3 … 1e-2.
При lr ниже 1e-4 P-tuning часто почти не обучается. Адаптер P-tuning не вливается в веса модели.
